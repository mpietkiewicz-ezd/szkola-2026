BEZPIECZNE DZIECI 5.2 — WERSJA PŁASKA DLA GITHUB PAGES

Ta paczka nie zawiera żadnych podfolderów. Wszystkie pliki można zaznaczyć jednocześnie i wgrać przez GitHub: Add file -> Upload files.

WAŻNE:
1. Nie usuwaj istniejącego pliku CNAME.
2. Nie usuwaj pliku weryfikacyjnego Google (google*.html).
3. Wgraj/zmień wszystkie pliki z tej paczki w katalogu głównym repozytorium.
4. Nowe poradniki są plikami .html w katalogu głównym, np. /procedura-atak-z-powietrza-szkola.html.
5. sitemap.xml i linki na stronie zostały dopasowane do wersji bez folderów.
