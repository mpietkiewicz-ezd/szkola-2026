BEZPIECZNE DZIECI 5.3 — WERSJA FINALNA / PŁASKA DLA GITHUB PAGES

Ta paczka nie zawiera żadnych podfolderów. Wszystkie pliki można zaznaczyć jednocześnie i wgrać przez GitHub: Add file -> Upload files.

WAŻNE:
1. Nie usuwaj istniejącego pliku CNAME.
2. Nie usuwaj pliku weryfikacyjnego Google (google*.html).
3. Wgraj lub zastąp wszystkie pliki z tej paczki w katalogu głównym repozytorium.
4. Poradniki są zwykłymi plikami .html w katalogu głównym.
5. Linki wewnętrzne, canonicale i sitemap.xml wskazują na adresy zakończone .html.
6. Po wdrożeniu sprawdź stronę główną oraz pięć adresów poradników.

Pliki poradników:
- procedura-atak-z-powietrza-szkola.html
- sygnaly-alarmowe-szkola.html
- miejsce-schronienia-w-szkole.html
- rodzice-alarm-w-szkole.html
- punkt-schronienia-a-miejsce-schronienia.html

- określenie „injecty” zostało usunięte z interfejsu; używane jest „zdarzenia losowe”,
